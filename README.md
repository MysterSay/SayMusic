# Say Music

Музичний плеєр для Windows, який об’єднує бібліотеку YouTube Music та Spotify, власні плейлисти й офлайн-прослуховування.

## Можливості

- Пошук музики та додавання треків, альбомів і плейлистів за посиланням.
- Підключення акаунтів YouTube Music і Spotify в окремих вікнах входу.
- Синхронізація вподобаних треків з підключених сервісів.
- Власні плейлисти, уподобані та перегляд музики за виконавцями.
- Черга відтворення, перемішування й повтор треку або списку.
- Радіо за треком та музичні рекомендації.
- Відтворення під час завантаження й попередня буферизація наступного треку.
- Кешування музики у вибраній папці та офлайн-режим.
- Медіаострівець і крайовий віджет для швидкого керування відтворенням.
- Налаштування теми, кольорів інтерфейсу та вигляду віджетів.
- Кошик видалених треків і повторна перевірка недоступних пісень.
- Український та англійський інтерфейс.

## Розширення браузера

Розширення для Microsoft Edge, Google Chrome та Brave дозволяє додавати музику з YouTube і Spotify до плеєра та передавати сесії для підключення акаунтів.

> Для треків Spotify плеєр знаходить відповідне аудіо на YouTube.
