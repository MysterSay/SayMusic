Рекомендації

Добірка поєднує знайомі пісні з бібліотеки та схожі треки. Історія прослуховувань зберігається локально. Коли черга закінчується, рекомендації можуть продовжити відтворення; режим повтору має пріоритет.

Це добірка Say Music, а не точна копія однойменної полиці YouTube Music. Офлайн використовуються тільки наявні аудіофайли.

Вигляд програми

Медіаострівець

Окремий мініплеєр у стилі Island Media Controls. Після згортання у трей музика продовжує грати. Лівий клік по значку повертає програму, правий — відкриває меню.

Наведи курсор на смужку, щоб розкрити острівець. Затисни та перетягни смужку до потрібного краю екрана.

При наближенні курсора з’являється назва треку. Наведи на смужку, щоб відкрити керування. Відступ від краю — 4 px.

Акрил: сильний блюр, тонування та шум. Скло: прозорий розмитий фон. Без рамки: прозорий фон без блюру. Mica: непрозоре тонування із зерном. «Свій фон» зберігається тільки в програмі.

Розширення

Кешування для офлайн прослуховування

Оригінальний формат WebM / M4A / Opus / MP3 зберігається без перекодування. ✓ біля треку означає, що перевірений аудіофайл є на ПК. Вимкнення автоматичного кешування не видаляє вже збережені файли. Зміна папки застосовується до нових завантажень.

Буферизується лише один наступний трек, після повного завантаження поточного. Якщо автоматичний кеш вимкнено, тимчасові буфери видаляються після завершення програми.

Видалені та проблемні пісні

Кошик зберігає пісні після видалення з бібліотеки. Проблемні пісні містять помилки імпорту й пошуку аудіо; їх можна перевірити повторно.

Компоненти

Вставити сесію з розширення

Скопіюй сесію в розширенні та встав її сюди.

Це дані входу в YouTube. Поле очищається після імпорту або закриття вікна; не публікуй його в скриншотах.

Підключити розширення

1. Додатковий міст для автозапуску

Якщо ти вже вставив сесію, цей крок можна пропустити. За потреби кнопка зареєструє Say Music для поточного користувача Windows у Chrome, Edge та Brave. Права адміністратора не потрібні. Якщо перемістиш папку програми — натисни кнопку повторно.

2. Завантаж розширення у браузер

  1. Натисни «Відкрити розширення браузера».
  2. Увімкни Developer mode / Режим розробника.
  3. Натисни Load unpacked / Завантажити розпаковане.
  4. У вікні вибору папки встав шлях нижче в адресний рядок і підтвердь вибір папки extension.
  5. Якщо Say Music уже встановлено з цієї папки, натисни ↻ на його картці. Підтвердь доступ до YouTube, якщо браузер запитає.

Якщо розширення було завантажено з іншої старої папки, видали ту копію та завантаж цю. Не встановлюй дві копії одночасно.

3. Перевір з’єднання

Кнопка відкриє YouTube Music із перевіркою зв’язку. Якщо розширення завантажене й має доступ до сайту, нижче з’явиться підтвердження. Google-акаунт для цієї перевірки не потрібний.

Якщо зв’язку немає: перевір кроки 1–2, дозволь розширенню працювати на YouTube, онови вкладку. За потреби перезапусти браузер. Say Music має залишатися відкритою.

4. Додавай музику

Біля лайка у рядку пісні буде кнопка ＋. У вікні поширення — «Додати трек/плейлист». Для додавання пісень передавати сесію браузера не потрібно.

Для точного списку YouTube Music LM окремо увійди на сайті, відкрий вікно розширення через значок у браузері та натисни «Підключити YouTube-акаунт».

Імпорт музики

Імпортуються до 10 000 треків за один запит. Імпорт працює у фоні; бібліотекою можна користуватися далі. Приватний список LM потребує підключеної сесії.
